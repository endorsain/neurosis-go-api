ULTIMO PROMPT, QUE CAMIO:

Qué cambié

Configuración centralizada en config.go
Se creó Config con:
ApplicationConfig
DatabaseConfig
ServerConfig
Se movió toda la lectura de variables de entorno desde main.go.
Se conservaron defaults actuales de base de datos:
DATABASE_URL
DB_HOST, DB_PORT, DB_NAME, DB_USER, DB_PASSWORD, DB_SSLMODE
Se agregaron defaults de servidor:
SERVER_HOST (vacío por defecto)
SERVER_PORT (8080)
timeouts (SERVER_READ_TIMEOUT, etc.)
DatabaseConfig.DSN() encapsula la construcción del DSN.
Infraestructura PostgreSQL en client.go
Se creó postgres.Client con responsabilidades de infraestructura:
abrir conexión (sql.Open)
configurar pool (SetMaxOpenConns, etc.)
verificar conexión (PingContext)
exponer DB() *sql.DB
cerrar (Close())
Logging de ciclo de conexión:
connecting to PostgreSQL
PostgreSQL connection established
failed to connect to PostgreSQL: ...
Transporte HTTP en router.go, server.go, json.go
Router general y middleware común en transport/http:
RequestID, RealIP, Recoverer
Servidor HTTP encapsulado:
NewServer(...)
Start()
Shutdown(ctx)
Address()
Utilidades JSON reutilizables:
WriteJSON
WriteError
Esto elimina duplicación de helpers HTTP por handler.
Handlers migrados a utilidades comunes y separación log/respuesta
get_me.go
get_by_id.go
list_users.go
register.go
